# Few-shot / Zero-shot（少样本 / 零样本计数）

> **定义**：横切范式。Few-shot：仅给少量目标示例（exemplar）即可对新类别 / 新场景计数；Zero-shot：不给示例，仅靠类别名称 / 语义提示对新类别计数。
>
> **收录边界**：以"跨类别 / 跨场景泛化、示例或语义条件计数"为主要贡献才归此；底层用密度图还是检测不作归类依据。若核心贡献只是普通单场景密度回归，归入对应主干 [Density_Map](Density_Map.md) / [Detection_based](Detection_based.md) / [Direct_Regression](Direct_Regression.md)。
