# Weakly / Semi / Self-supervised（弱 / 半 / 自监督）

> **定义**：横切范式，按"标注依赖程度"划分，降低点级标注成本——
> - Weakly-supervised 弱监督：仅用图级总数、框或区域计数等弱标签；
> - Semi-supervised 半监督：少量标注 + 大量无标注数据；
> - Self-supervised 自监督：无人工标签预训练后迁移到计数。
>
> **收录边界**：以"监督范式本身"为主要贡献才归此；底层回归技术（密度图 / 检测 / 直接回归）不作为归类依据。普通全监督密度回归归入对应主干。
