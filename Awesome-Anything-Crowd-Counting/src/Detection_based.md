# Detection-based（检测后计数）

> **定义**：先用目标检测器（两阶段 / 单阶段 / DETR 类）框出每个个体，再统计检测框数量得到计数；稀疏场景下定位与计数同时完成。
>
> **收录边界（已并入的相邻变体，不单列）**：
> - 检测 + 跟踪去重的视频计数（以检测为主要路线时先放此，不单列 Video 文件）；
> - 密集遮挡导致检测失效、转而回归密度图的，归入 [Density_Map](Density_Map.md)。
